# Instaladores do kit

Instaladores dos programas com `instalacao = pasta` no `software.csv`. O script baixa daqui pelo GitHub Pages e só executa se o SHA-256 bater.

O repositório é público: só programas gratuitos cuja licença permite redistribuir. Nada pago, interno ou de licença restrita. Limite de 100 MB por arquivo.

Como usar: ver [MANUTENCAO.md](../MANUTENCAO.md).
